
# PB3_PD12_Jirgensons_Aivars

## Projekta apraksts

Solar Cargo 20. gadadienas svinību viesu grāmata.

Projekts izveidots, izmantojot HTML, PHP un MySQL. Apmeklētāji var ievadīt savu vārdu un novēlējumu. Ievadītie dati tiek saglabāti MySQL datubāzē un attēloti tabulā zem reģistrācijas formas.

## Projekta palaišana

1. Instalēt un palaist XAMPP.
2. Ieslēgt Apache un MySQL.
3. Ievietot projekta mapi `PB3_PD12_Jirgensons_Aivars` XAMPP mapē `htdocs`.
4. Izmantojot phpMyAdmin, izveidot datubāzi `viesu_gramata` ar tabulu `Viesu_gramata` un kolonnām `id`, `vards`, `zina`.
5. Pārbaudīt datubāzes savienojuma parametrus failā `index.php`.
6. Atvērt pārlūkā:

   http://localhost/PB3_PD12_Jirgensons_Aivars/index.php
